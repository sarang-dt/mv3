# 📖 사역반 성경암송 앱

남가주사랑의교회 사역반 성경 구절을 듣고 반복 재생하며 암송하기 위한 웹 기반 학습 앱입니다.

**바로가기: https://sarang-dt.github.io/mv3/**

## ✨ 주요 기능

- **29개 과 · 총 48개 구절**: 권·과별로 정리된 암송 구절
- **한국어 / English 전환**: 음성과 화면 텍스트(주제·장절·본문)가 함께 전환
- **여성 / 남성 음성 선택**: 4가지 조합 (한국어·영어 × 여성·남성)
- **선택 기억**: 언어·음성 설정이 브라우저에 저장되어 다음 방문 시 그대로 유지
- **홈 화면 설치**: 아이폰·안드로이드 홈 화면에 추가하면 앱처럼 전체화면으로 실행
- **오프라인 재생**: 한 번 들은 구절은 기기에 저장되어 데이터 없이 재생
- **잠금화면 조작**: 잠금화면·알림창에서 구절 확인과 재생/일시정지
- **제목 + 구절 순서 재생**: 매 재생 시 주제 제목 음성 후 구절 재생
- **개별/전체 재생 선택**: 1절만 · 2절만 · 전체(1절+2절) 선택 가능 (기본값: 전체)
- **반복 횟수 지정**: 1·2·3·5·7·10·20회 또는 무한 반복
- **재생 속도 조절**: 1x · 1.25x · 1.5x · 2x


## 🚀 사용 방법

### 1. 과 선택
상단 탭에서 과를 선택합니다. 탭은 `권-과` 형식으로 표기됩니다 (예: `1-1과`, `2-3과`).

### 2. 설정 (⚙ 하단 설정 바)
- **언어**: 한국어 / English
- **음성**: 여성 / 남성
- **재생 구간**: 1절만 / 2절만 / 전체
- **반복 횟수**: 1 ~ 20회 또는 무한(∞)

### 3. 재생
가운데 재생 버튼을 누르면 `제목 → 1절 → 2절` 순으로 재생됩니다.
구절 카드의 작은 재생 버튼을 누르면 해당 절만 반복 재생합니다.

### 4. 과 이동
플레이어의 ◀ ▶ 버튼 또는 상단 탭으로 이동합니다.

## 📲 휴대폰 홈 화면에 추가

**아이폰 (Safari)**: 공유 버튼 → `홈 화면에 추가`
**안드로이드 (Chrome)**: 메뉴(⋮) → `홈 화면에 추가`

### 오프라인 사용
한 번 재생한 구절은 기기에 저장되어 인터넷 없이도 재생됩니다.
과를 열어두면 해당 과의 음성을 미리 받아 둡니다.

## 🔧 기술 사양

- **프레임워크 없음**: HTML·CSS·JavaScript 단일 파일, 빌드 과정 불필요
- **PWA**: manifest + 서비스워커로 설치·오프라인 지원
- **음성**: ElevenLabs `eleven_multilingual_v2` (mp3 44.1kHz 128kbps)
- **장절 낭독**: 구절 음성은 장절을 앞에서 한 번 읽고 본문이 이어집니다
- **강조색**: 녹색 (#6ed48a)
- **호스팅**: GitHub Pages
